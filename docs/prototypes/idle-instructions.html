Shared behaviour

  • After 10 seconds without keyboard or mouse input, title and instructions fade in together over 1.2 seconds.
  • Player input fades them out over 0.25 seconds. Holding a movement key counts as activity.
  • Automatic flight and automatic prompt changes do not reset the timer. The overlay stays still once visible.
  • Keep clear of the prompt caption. Hide the idle overlay while F1 diagnostics or the prompt editor is open.
  • Only player controls appear here. Settings stay behind the F1 lock.
