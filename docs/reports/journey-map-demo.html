The first-person experience and its live map, side by side. Watch the route and captured views accumulate, disappear during inactivity, then return at the player's current position.

What to watch for

  1. 00:00 to 00:26Traversal builds the route. Views attach to their capture positions and viewing directions; prompt changes appear on the map.

About this recording

Scripted movement and look input drive the running application. The two live window renders are composed side by side. The video plays continuously at real speed.

This demo uses a separate settings copy. Automatic movement starts after two seconds without input, which hides the map immediately. Prompt selection advances every twelve seconds. Your saved settings are unchanged.

The run saved two journey archives, containing 60 and 20 original images, plus the SVG maps, prompt history, and interactive viewers. Prompt timestamps on the map measure time since the application session began.
