# Thirty-minute performance run, 5 September 2026

The app completed 1,800.005 measured seconds, beginning at its first AI frame at
17:49:24 local time. It exited normally with no worker error or resolution
fallback. Display throughput held steady; AI throughput fluctuated and was lower
near the end. This run does not establish reliability for a full week.

## Setup

- Intel Core Ultra 7 155H, NVIDIA RTX 4070 Laptop GPU, driver 581.80.
- Current saved configuration: fullscreen, 384x256 generation, one step, CFG 1.5,
  reprojection off, 60 FPS display target, 15 FPS conditioning target.
- Prompt auto-advance every 24 seconds with random tuning and regional colours.
- Fifteen-pixel trail and enlarged idle instructions enabled.
- Config copied for monitoring; only idle-flight delay changed to two seconds.
  The original config was verified unchanged.
- No concurrent GPU tests. Screenshot correctness was tested separately; no
  Enter capture events were recorded during the timed run.

Command:

```powershell
runtime/python/python.exe tools/soak_test.py --minutes 30 --output logs/performance/soak-20260905-final
```

The prompt cache reached its 64-entry limit around halfway and stayed capped.
Private memory grew by about 28 MiB between the comparison windows, roughly
0.5 percent, with a peak of 5,623.6 MiB. It rose slowly after cache saturation;
this cannot yet distinguish allocator reuse from a small leak. Do not extrapolate
this short run into a weekly memory estimate.

## What still needs investigation

The 49 pauses above 100 ms amount to about one every 37 seconds. They are rare
relative to the frame count but noticeable. Full garbage collection reached
101 ms, world updates reached 130 ms, and scene rendering reached 149 ms.
These are measured contributors worth tracing; per-minute aggregation does not
establish which event caused each individual stall.

Late-run median AI throughput was about 12 percent lower than the early window,
although it recovered repeatedly during the run. GPU temperature stayed below
66 degrees C. The recording does not isolate prompt variation, system scheduling
or power management as the cause. A controlled follow-up needs fixed settings
and timestamped stall events before changing the rendering path.

Run the same monitor on the exhibition computer for the full intended duration
with `--minutes 10080`. That is the remaining test for week-long operation,
including memory behaviour after many hours. No rendering quality was reduced
to obtain these results.

Raw local records are in `logs/performance/soak-20260905-final/`:
`run.json`, `config.json`, `summary.json`, `minutes.csv`, `minutes.jsonl` and
`resources.jsonl`. These runtime artifacts are ignored by Git.

All 29 focused tests passed across screenshot capture, idle typography, hotkey
locking, render cadence, trail rendering and monitoring. Screenshot comparisons
cover raw, reprojected and fallback presentation. Saved pixels match the clean
AI presentation exactly, including crop and sharpening, while excluding text
and the trail. PNG write failures are reported without crashing the app.
