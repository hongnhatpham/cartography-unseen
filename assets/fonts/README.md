The idle title uses Space Grotesk SemiBold and the controls use IBM Plex Mono
Regular, matching the typography at https://emergentplay.bynhat.com/.

These Latin WOFF files are bundled for offline use and loaded directly by
pygame's FreeType support. Both fonts use the SIL Open Font License 1.1;
their copyright notices and licenses are included alongside them.
